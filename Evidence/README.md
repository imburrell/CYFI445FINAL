# Evidence and Reproduction Documentation

This folder contains supporting evidence, trace exports, and reproduction documentation collected during the CYFI 445 Final Project.

## Contents

- Evidence & Reproduction Log
- JSON Trace Exports
- Trace Analysis Outputs
- Supporting Project Documentation

## Purpose

The materials in this folder document the procedures used to collect and analyze trace information throughout the project.

These files support reproducibility by documenting how Hermes Agent, Langfuse, export-trace, and trace-analyzer were configured and used during testing and validation activities.
