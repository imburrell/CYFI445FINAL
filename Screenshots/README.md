# Experimental Screenshots

This folder contains screenshots collected from Hermes Agent and Langfuse during execution of the M0, M1, M2, F1, and F2 test scenarios.

## Included Screenshots

- M0 Prompt and Response
- M1 Prompt and Response
- M2 Prompt and Response

## Purpose

These screenshots document the execution of each experimental scenario and provide supporting evidence for the Experimental Method section of the final report.

The screenshots were collected from Langfuse traces and demonstrate the prompts, responses, tool calls, and execution flows observed during testing.
