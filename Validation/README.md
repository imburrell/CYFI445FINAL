# Validation Results

This folder contains validation outputs and graph mutation testing results generated during the CYFI 445 Final Project.

## Contents

- Validation Results
- Graph Mutation Test Results
- Validation Scorecards
- Analysis Artifacts

## Purpose

Validation was performed using the custom trace-analyzer workflow. The validator compared live trace information against independently exported reference records and generated scorecards, discrepancy reports, graph artifacts, and mutation-testing results.

These files were used to verify graph accuracy, identify discrepancies, and demonstrate the effectiveness of the validation process.
